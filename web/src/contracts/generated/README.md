# contracts/generated

Generated by `contracts/scripts/export-abi.ts` — do not edit by hand.

| File | Content |
|---|---|
| `LevelNFT.abi.ts` / `ForgeCoin.abi.ts` | `as const` ABIs (typed for viem/wagmi) |
| `*.json` | `{ contractName, abi }` |
| `addresses.json` | `{ "<chainId>": { LevelNFT, ForgeCoin } }` from Ignition deployments |

Regenerate: `cd contracts && npx hardhat build && npm run export-abi` (or `npm run deploy:local` at the repo root).
`index.ts` (hand-written) re-exports them as `levelNftAbi` / `forgeCoinAbi` / `deployedAddresses`.
