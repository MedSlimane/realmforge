# Mario asset sources

Nintendo property, used for a private educational class demo only; do not distribute publicly; Kenney CC0 pack remains the public-safe fallback.

Only raster game imagery and frame metadata are curated. No Nintendo code, ROMs, encryption keys, executable game code, or Scratch gameplay scripts are included in the pack. The OpenWE mirror has an AGPL software licence; none of its executable code is reused. That software licence does not turn Nintendo artwork into freely licensed assets. Source rights and renderer provenance are recorded separately below.

## Download methods actually tested

- The Spriters Resource: direct HTTP requests returned 403. Real Playwright Chromium (installed Chromium 1243) also reached Cloudflare verification with HTTP 403; browser cookies did not provide a usable image response.
- Wayback URLs tested for the old sheet path returned 404, including the requested `2025id_` form.
- Successful method: public GitHub image/frame mirrors, content-addressed Scratch image downloads from credited collections, and the Super Mario Wiki native Grinder capture. The itch.io browser download worked, but its sheet identifies **NSMB Wii Small Mario, D. Dazzle** and is **not used** in this pack. The Scratch fan-vector Goomba and traced Mario sheet were also rejected.

Scratch image names are content hashes. `sources.json` records every exact download URL and SHA-256, including unused initial candidate frames, so raw downloads can be verified. `slicing.json` records every exact pixel rectangle and source composition.
